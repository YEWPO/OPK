# 曲谱／录音打开教程

[English](performance.md)

在 **帮助 → 曲谱／录音打开教程** 中可离线阅读本文。要听到演奏声音，请先通过 **音源 → 导入／替换音源** 导入 SF2，详见[音源导入教程](soundfont.zh-CN.md)。

## 打开演奏文件

1. 选择 **文件 → 打开 EOP / 演奏**。
2. 选择 Everyone Piano 的 `.eop` 文件或 OpenKeys 的 `.eopiano.json` 录音文件。
3. 检查显示的标题及兼容性提示，再点击 **播放**。

此入口不支持 PDF 曲谱、图片、EOPM、MIDI、MusicXML 或音频文件。修改扩展名不会转换文件格式。无法读取、损坏或不支持的文件会报错；部分尚未支持的 EOP 控制会跳过并显示警告，其效果可能与原演奏不同。

## 播放控制

- **播放／暂停** 用于开始或暂停；**停止** 返回开头，播放结束后再次播放也会从头开始。
- **速度** 可在 0.25×～2× 之间调整，不改变音高。
- 点击进度条可以跳转；也可拖动后松开跳转，保留原来的播放或暂停状态。
- 回放采用文件中的音高、左右手和延音。文件提供演奏设置时，控件在播放或暂停期间只读显示文件配置，缺失值显示“未知”；停止后恢复现场设置。
- **演奏设置** 中的 **延音** 开关只影响现场弹奏，不会给已打开的曲目添加延音。

想先试用时，选择 **文件 → 演奏示例**，再点击 **播放**，无需下载曲目。

## 录制、保存与重新打开

1. 导入音源，并通过 **输出 → 音频设置** 连接音频输出。
2. 设置现场调号、八度和力度。需要时打开 **延音**，无需按住空格；再次点击即可关闭。
3. 点击 **录制**，使用电脑键盘或任一屏幕键盘弹奏。延音变化也会录入；开始录制前已开启的延音同样会保存。
4. 点击 **结束录制**（或 **停止**），再选择 **文件 → 保存演奏**。
5. 保存为 `.eopiano.json`，以后通过 **文件 → 打开 EOP / 演奏** 回放。

录音保存演奏事件，不是麦克风音频，也不导出 WAV／MP3。结束录制会补齐仍按住的音符和踏板释放，确保文件正常结束。现场延音的选择保留供下一次弹奏使用；每次启动软件时重置为关闭。紧急止音（`Ctrl+Alt+F12`）会关闭延音并清理全部声音。

存在未保存录音时，打开其他文件或关闭窗口会询问是否保存；选择取消可继续编辑。OpenKeys 不导出 EOP 文件。
