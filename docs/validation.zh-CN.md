# 验证与发布验收

[English](validation.md)

## 自动检查

```sh
ctest --test-dir build --output-on-failure
python3 tools/verify_resources.py
```

测试覆盖：

- 按住重复抑制、跨移调的释放快照、踏板引用计数、力度修饰、越界音符及键位持久化。
- 原生录制往返（含中文标题）、原子保存失败时保留旧文件、错误事件及踏板/音符配对。
- EOP v200/v201/v301、多层音符、v201 零段容器、v200 力度、截断及确定性变异压力测试。
- 音频时钟驱动的播放/暂停/恢复/停止/重播、速度变化、队列过载、生成 SF2 的实际 FluidSynth 加载渲染、止音与音量。
- GUI 导入失败时保留已有状态、文本输入隔离、紧急快捷键及无音频设备启动。
- 两种屏幕键盘的鼠标演奏：拖动切换、黑键优先、窗口外释放、焦点/隐藏/鼠标捕获取消、右键编辑、无声视觉反馈和内嵌图标尺寸。实体/鼠标输入合并覆盖音符、延音和力度修饰、两种释放顺序、重复抑制及跨移调录制事件配对。
- SF2 应用副本：中文路径、持久化、重复导入、源文件删除、替换清理、损坏文件、取消、写入/配置失败和错误元数据恢复。
- 首次使用提示、内嵌离线教程、导入失败保留、重启加载及旧版外部音源路径的显式迁移。
- 中英文主界面及控件、系统语言回退、偏好持久化、安装默认语言、已有选择优先、命令行语言覆盖、离线教程双语跳转和嵌入翻译。
- 使用生成夹具的无界面全音域/力度采样检查及 PCM16 WAV 输出。可选 `real_soundfont` 集成测试通过 `OPENKEYS_TEST_SOUNDFONT` 接收用户音源；未配置时明确跳过。

资源检查验证英文默认文档、中文对应文档、语言导航、相对链接、图片引用、翻译覆盖和占位符、图标尺寸及双语预览。截图由当前构建生成，不依赖音源或音频硬件。

本地自动验证使用 Linux、Qt 6.11.2、FluidSynth 2.6.1 和 PortAudio 19。测试音源是生成的夹具，不代表第三方钢琴音源通过听感验证。构建或分发不需要乐器音源。

AddressSanitizer 和 UndefinedBehaviorSanitizer 检查采用 `ASAN_OPTIONS=detect_leaks=0 UBSAN_OPTIONS=halt_on_error=1`。当前环境的 ptrace 限制使 LeakSanitizer 无法运行，因此不宣称完成泄漏检测。Windows CI 自动验证静默安装、升级、快捷方式和卸载；实体输出及交互界面仍需实机验收。

## Windows 实机验收（待完成）

目标为 Windows 11 x64 和 Windows 10 22H2 x64。记录系统版本、CPU、内存、音源校验和、键盘、音频设备/驱动、有线输出类型、共享/独占模式、采样率及缓冲。

1. 在无开发工具的干净离线机器安装。确认无附带或自动下载音源，首次提示和完整教程均能离线打开。导入本地 SF2，等待复制/加载，删除原文件后重启，确认应用副本可用。重复中文路径和 100%、150%、200% DPI。
   分别选择英文和中文安装；确认所有标准/自定义页面、升级确认和卸载提示使用对应语言。首次应用语言继承安装选择；已有手动选择（包括跟随系统）不被升级覆盖。切换应用语言并重启，检查主界面、弹窗、错误、键盘标注和教程；检查教程双语链接。桌面和开始菜单选项默认均开启，分别取消后不创建对应快捷方式；所有快捷方式均能启动。检查重装、升级和卸载、完整目录清理。核对资源管理器、窗口/任务栏、快捷方式、安装和卸载图标，在各 DPI 和深浅色桌面下均清晰。
2. 更换音源、取消/中断导入、尝试损坏 SF2 和已满/不可写存储。失败时保留原始文件和旧配置；成功替换后，旧采样器释放再清理旧应用副本。
3. 快速弹奏、和弦、两键同音、延音、按住时改变调名/八度、文本编辑、焦点切换和模态窗口，确认没有重复、错误释放或卡音。测试双延音键及左右力度键同时使用。
   鼠标在两种屏幕键盘拖动，经过黑白琴键和空白；实体键和对应屏幕键同时按住并按两种顺序释放，包括 Space/Shift。测试窗口外松开、切换窗口、打开对话框和紧急止音。后台模式下切换窗口应释放鼠标音符，实体输入继续。没有音源时仍有悬停/按下反馈及启用声音的提示。
4. 开启后台演奏，切换到看谱窗口演奏；`Ctrl+Alt+F12` 应止音并关闭后台输入。测试快捷键冲突和拔掉键盘，普通输入仍到达前台程序。
5. 导入各版本真实 EOP，与 Everyone Piano 对比并记录差异；确认未知控制警告。按住音符/踏板时暂停、改速和继续，停止后从头回放。
6. 录制双手与延音，琴键仍按住时结束。保存重开并比较时序、力度与延音；取消覆盖/关闭提示时保留录制。
7. 连续 30 分钟密集回放和现场演奏，包含长延音，记录欠载、内存峰值、CPU 和爆音/掉音。合成自动测试不替代听感测试。
8. 拔掉或切换输出，不应卡住输入或持续发声。重新进入设置发现和重连设备；不支持独占时清晰提示回退共享。采样率变化时重新加载采样器，音高保持不变。
9. 使用时间相关的按键动作标记与模拟输出录音（外部录音/回环装置），完成至少 100 次按键到出声测量，报告 P50/P95/最大值和方法。低延迟模式目标 P95 ≤20 ms；驱动报告延迟和请求缓冲时长不能代替测量。
